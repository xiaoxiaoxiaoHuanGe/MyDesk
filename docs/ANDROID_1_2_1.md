# MyDesk 1.2.1：步数界面优化

- 工作台移除重复的步数快捷卡片；需要处理中的步数异常仍可进入任务记录。
- 步数页面复用统一标题组件，背景、圆角和居中方式与其他主页面一致。
- 预设名称保留字段标签和单行输入，取消空白时的示例提示，避免窄屏聚焦后增高。
- 保存配置与立即开始等宽，保留描边次按钮和实心主按钮的区分。
- 最近提交异常中的工作流原因链接移入提交状态卡片，与步数、失败状态和说明一起展示。

Android 版本为 1.2.1（versionCode 8），沿用正式签名，可覆盖安装。此次仅更新客户端，继续兼容 1.2.0 后端，不涉及服务器数据迁移。按用户要求不连接手机、不安装 APK、不进行手机测试。
