# MyDesk Android 1.5.0

版本 1.5.0，versionCode 15，包名 app.mydesk.android，使用既有正式签名。

- 提醒支持每天、周一至周五、周末和自定义星期；详情可修改频率、暂停或恢复。
- 完成或延后只影响本次，后续固定时间继续提醒；断网后使用本地缓存规则调度。
- 小时、分钟和倒计时秒数均可循环滚动；日期不循环。
- 每次实际进入提醒页，初始化为当前设置时区的下一分钟，支持跨天进位；普通同步及旋转不重置编辑内容。
- 名称选填，空白默认“提醒”，同名提醒各自独立。
- 本机 IP 保留 IP111 返回的完整地区；仅返回美国国家信息时，对已测得的明确 IP 补查州和城市，失败保留原结果。
- Web 提醒同步支持空名称、重复创建、暂停/恢复、时间循环及重新进入初始化。

升级需要先部署本版 Python 后端，再把原正式签名 APK 发布到服务器 release 渠道。旧提醒保留为单次提醒，重复规则放在新增独立表中，原提醒表的八列结构保持不变，避免旧后端回退时无法创建提醒。发布前备份数据和原镜像。交付流程见 [应用内更新](APP_UPDATES.md)。

手机验收：在设置中检查更新并安装 1.5.0；验证每次进入的下一分钟、跨 59/00 滚动、空名称及重复名称；建立每日/自定义星期提醒，分别测试完成本次、延后、暂停和恢复。最后测试断网、锁屏及重启后的后续提醒，并核对三项本机出口 IP 和地区。
