# 服务接入

入口：Android 设置 → 外部服务接入。各项单独管理、保存凭据和检查连接。空白凭据仅在编辑已有且身份未变的接入时保留；新增接入必须填写完整凭据。

## GitHub Actions

GitHub 任务 → 添加任务 → 自定义任务。填写任务名称、自己的仓库所有者、仓库名、工作流文件名（例如 daily.yml）、分支和独立 Token。

Fine-grained Token 只选择需要的仓库，普通运行查询授予 Actions: Read-only。微信步数的主动 workflow_dispatch 操作需要 Actions: Read and write，使用单独 Token。不要把业务 Cookie 或 GitHub 内置 GITHUB_TOKEN 填入此处。

默认“工作流状态”读取 GitHub 的运行结论。需要业务结果时在一个明确命名的实际业务步骤中输出一行：

```text
MYDESK_RESULT={"version":1,"status":"success","message":"签到成功","metrics":[{"label":"积分","value":9,"unit":"分"}]}
```

在 APP 高级设置选择“标准结果”，填写该步骤真实的 name。status 支持 success / failed / warning / unknown，message 1–300 字，最多 12 个指标。结果必须来自真实业务返回值，不用固定成功字符串掩盖失败。不要输出账号、Token、Cookie 等敏感信息。

保留 52 辅助论坛和 GLaDOS 现有日志格式适配，但预设不填任何人的仓库账号。使用自己的仓库并确认文件名和步骤名称一致。普通自定义工作流无需使用这些适配。

后台约 10 分钟查询一次，立即同步绕过等待。超期默认 36 小时，适合每日任务；每周任务可设为 180 小时。根据实际周期和允许延迟设置每项的超期时长。

## Gmail

Gmail 邮件 → 添加邮箱，填写名称、完整邮箱地址和该账号的应用专用密码；通常需要先启用 Google 两步验证。企业账号可能受管理员策略限制。更改 Google 账号密码后，原应用专用密码可能失效。

多个邮箱分别管理凭据。默认合并展示按收件时间排序的最近 3 封；筛选单个邮箱后显示它配置的 3–5 封邮件。只读取标题信息，不取正文或标记已读。后台约每 2 分钟查询。

HTTP 代理需要填写后端可访问的地址和 HTTP 端口，支持无需账号认证的 HTTP CONNECT。Gmail 默认连接 imap.gmail.com:993；Ping 网页地址不能验证邮件连接。

## 服务器

支持 1Panel v2 和 Beszel。1Panel 填写面板根地址及 API Key，不包含登录安全入口或 API 路径。启用 API，允许后端出口 IP 通过白名单，默认使用兼容 MD5 签名，支持按面板选择 HMAC-SHA256。

读取 CPU、内存、根磁盘、负载及网络累计计数。不同监控服务支持的字段不同；1Panel 当前接口没有适用的温度值时显示未知，不生成虚假读数。

Beszel 填写服务器地址、登录邮箱和密码。服务器监控约每分钟查询。

## 配置备份

设置 → 备份与恢复 → 导出，设置至少 12 位密码，由系统文件选择器保存加密文件。导入时先预览，再选择合并或替换。恢复前原配置会加密保存在后端 config-backups 目录，最多保留 10 份。

备份含接入凭据及配置，不含登录账号数据库、会话、设备注册、提醒和任务历史。迁移完整实例需另行备份 data 目录。导出的文件、密码和解密内容均不要提交到公共仓库。
