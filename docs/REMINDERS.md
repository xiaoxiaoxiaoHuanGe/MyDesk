# 提醒与重复规则

提醒支持仅一次、每天、周一至周五、周末和自定义星期。工作日仅表示周一至周五，不判断调休或法定节假日。倒计时保持单次。

提醒事项选填，空白默认保存为“提醒”，允许同名，每条按独立 ID 操作。每次实际进入提醒页时，日期及时间初始化为当前设置时区的下一分钟；跨小时及跨天正常进位。在页面编辑期间、普通同步及旋转屏幕时不覆盖已选时间。

重复规则保存固定时分、星期及创建时的时区。完成只跳过本次，延后只改变本次；暂停保留配置，恢复重新计算下一次。取消结束整条重复提醒。下一轮无需等待上一轮完成。长时间离线后只显示最近到期的一轮，避免集中补发；手机缓存规则并持续注册下一轮本地闹钟。每一轮有确定的独立版本，旧通知及多端重试不能完成下一轮。

春季夏令时不存在的时间跳过当天，秋季重复时间只执行一次。修改工作台时区不会静默改变已保存规则的时区。

本机 IP 从当前手机直接访问 IP111 的三个固定地址，不经过 MyDesk 后端。保存完整地区文字；仅返回国家的美国 IP 才对该明确 IP 补查州及城市。地区补查失败不影响原 IP 与国家展示。

发布继续遵守 [应用内更新交付约定](APP_UPDATES.md)：维护者先完成后端兼容更新，再构建原正式签名、更高版本号 APK，并发布至现有服务器 release 渠道。用户在 App 内更新后完成真机验收。
