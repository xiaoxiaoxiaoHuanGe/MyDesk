# MyDesk 1.4.1

Android 版本：1.4.1，versionCode：12。沿用已有正式签名，通过系统安装器覆盖升级并保留应用数据。

## 界面调整

- 设置页的「通知接入」采用与其他设置卡片一致的图标、入口行和箭头，收件箱入口显示未读数量。
- 通知来源分为列表、添加和详情，统一状态标签、最近接收时间与操作控件；接收地址的复制提示精简为一行。
- 收件箱采用消息卡片，分别显示标题、摘要、来源、时间和未读状态；消息详情支持复制正文与标为已读。
- 未读标签正确识别服务端返回的空已读时间，已排队同步的已读操作不会重新显示为未读。
- 提醒卡片将状态、时间、详情箭头和完成图标置于顶部，标题单独显示在下方。长标题和大字体允许自然增高，图标保留 48dp 点击区域。

## 国内出口查询

ip111.cn 对默认 `okhttp/4.12.0` 请求标识返回 HTTP 503；本机交替测试三次均复现，同条件下 `Mozilla/5.0` 三次返回 HTTP 200。
国内查询改用实测可用的兼容请求标识，继续由当前设备直接查询；国外和 Google 出口保持独立请求与状态。返回错误页面时不会把其中的 IP 当作查询结果。

## 发布与应用内更新

正式 APK、源码包、应用内更新部署包及 SHA-256 校验文件发布在 GitHub Release。
GitHub Release 发布后，还需把 APK 与登记文件放入云服务器的更新目录，最后原子替换 `release.json`。
手机进入「设置 → 应用更新 → 检查更新」，下载后点击安装，由 Android 系统确认覆盖升级。
完整部署说明见 [APP_UPDATES.md](APP_UPDATES.md)。
