# Android 1.1.1

本次更新针对 Android APP，兼容现有 1.1.0 后端，无需迁移数据库。

- 微信步数入口及默认任务名称改为“自动任务”，自定义预设名称保留。
- 简化说明，关闭每日重复时隐藏每日开始时间。
- 修复退出页面取消前台同步时，提醒缓存已写入但系统闹钟尚未登记的竞态。缓存更新与闹钟登记在同一个不可取消的本机操作中完成，服务端请求仍可取消，账号退出仍通过原有会话锁清理提醒。
- 正式版记录不包含标题、提醒 ID、服务地址或凭据的调度阶段日志，方便排查设备上的后台提醒问题。

正式版沿用已有签名，可覆盖安装并保留登录、设置及本机缓存。不要先卸载 APP。

本次调整不改变步数提交规则：先提交起始步数，按固定间隔增加，首次超过终止步数的提交成功后结束。预设只填入参数，任务仍可随时终止。

通知和横幅还取决于系统权限及通知渠道；本次验证范围与结果以版本发布说明为准。
