# MyDesk 1.4.0：App 长期登录与电脑扫码登录

Android 版本为 1.4.0（versionCode 11），继续使用原正式签名，可以覆盖安装。

- App 保留服务器地址、账号和密码登录，会话不再按时间到期。关闭 App、重启手机或重启后端后可继续使用；退出账号、修改密码、移除设备会使相关会话失效。
- 电脑网页登录页默认显示 App 扫码登录，也可以切换到账号密码登录。
- App 设置中「本机设备」的编辑图标右侧增加「扫一扫」。扫描后展示服务器和待登录浏览器，只有点击「确认登录」后电脑才会登录。
- 二维码有效期两分钟，只能使用一次，过期后可刷新；App 只接受当前连接服务器的二维码。网页会话仍为七天。
- 新增设备 IP 出口卡片：进入 App 时查询本机网络出口，支持手动刷新。

此次发布包含最新 1.3.1 功能以及上述改动，需要同时更新后端和 App。仍有效的旧 App 会话在首次成功连接时转为长期会话；已经到期的旧会话需要重新输入账号密码。手机和电脑应使用相同的 HTTPS 服务器地址。

后端新增扫码请求表，保留既有账号、会话及业务数据。发布包不含账号密码、运行数据、正式签名私钥或本地 Firebase 配置。正式 APK 沿用签名，安装仍由 Android 系统确认；自动化验证不替代真机相机和覆盖安装验收。

操作说明见 [扫码登录](QR_LOGIN.md) 和 [应用内更新](APP_UPDATES.md)。
