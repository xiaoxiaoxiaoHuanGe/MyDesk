# MyDesk 1.2.0：步数独立页面

底部入口顺序为工作台、提醒、步数、设置。步数页面包含自动任务、手动提交、任务记录三个分页。

## 保存与执行

自动任务只有两个主要操作：

- 保存配置：在同一个数据库事务中更新当前参数、每日安排和选中的快捷配置；没有选中配置时新建。重复名称、无效参数或过期版本会拒绝整个保存操作，不留下部分更新。
- 立即开始：按当前输入开始一轮任务，并保存每日安排；不会覆盖选中的快捷配置。

选取快捷配置只填入表单，包括每日重复及开始时间，不会执行或启用每日计划。保存配置或立即开始之后，每日安排才生效。每日重复从次日开始，按服务器配置时区执行。

管理菜单用于新建、删除和调整配置顺序。历史运行参数不随配置修改而改变。

表单按三排排列：名称与预计耗时；起始与终止步数；每次增量与间隔。标题与关闭按钮、每日重复文字与开关均垂直居中。

## 已知晓

工作台步数异常事项提供已知晓操作。服务器保存本次异常的确认标识，重新打开 App 或重启服务器后不会再次显示同一事项。确认只移除待处理提示，不改变失败记录，也不会停止、恢复任务或重新提交步数。后续提交失败，即使属于同一轮任务，也会形成新的事项。

## 运行记录

自动任务表单下方不再堆叠历史提交。任务记录页面按每次启动单独展示当前轮次与历史轮次。点击一轮后只查询该轮记录，支持加载更早提交；运行中的记录随同步更新。失败提交提供对应 GitHub Actions 链接。

## 安装与兼容

本版 Android 版本为 1.2.0（versionCode 7），继续使用原正式签名，可覆盖安装并保留登录和本机数据。服务器同步升级为 1.2.0；新增确认表和配置字段均为增量更新，保留已有配置、任务和提交记录。旧客户端的原计划保存、预设保存和运行接口继续可用。

验证包含自动化后端与 Compose UI 测试、正式签名校验、服务器隔离容器测试与部署后检查。此次按用户要求不连接手机，不进行手机安装或测试。
