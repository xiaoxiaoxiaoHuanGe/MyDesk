# MyDesk Android 1.4.3

版本 1.4.3，versionCode 14，包名 app.mydesk.android，支持 Android 8.0 及以上。使用原正式签名，可以覆盖既有正式版。

## 本次变化

- “最近通知”的新消息支持系统通知、横幅与锁屏展示；点击通知打开对应消息详情。
- 增加“后台实时接收”开关。开启后使用静音常驻状态通知，返回桌面后继续接收新消息。
- 前后台共享同一条实时连接，断线自动重连；关闭开关、退出登录或会话失效时停止后台接收。
- REST、WebSocket 与可选原生推送共享消息去重记录；首次同步不补弹历史消息，已读消息不重放。
- 既有本地定时提醒继续由 AlarmManager 执行。

## 更新与开启

1. 在 APP 设置 → 应用更新 → 检查更新中安装 1.4.3，或使用 GitHub Release 的原签名 APK 覆盖安装。
2. 打开 APP 并完成同步，在设置 → 后台实时接收中开启“桌面与锁屏接收”。开关默认关闭。
3. 等待常驻状态通知显示已连接，再返回桌面或锁屏。

系统通知权限、通知频道和省电设置影响实际表现。可从“后台与电池设置”进入系统应用设置；用户强行停止 APP 后需要重新打开。具体行为见 [后台实时接收](BACKGROUND_RECEIVING.md)。
