# MyDesk Android 1.3.0（9）

- 步数自动任务支持基准增量 ±10% 随机浮动。新配置默认开启，旧配置缺少字段按固定解释；后端统一抽取并保存下一次数值，两端预览显示范围。30000 封顶与严格超过终止值规则保持。
- 设置增加应用更新，同源认证下载、校验真实 APK 及签名，用户手动确认系统安装。无更新/旧后端保持可用。详见 [更新发布与真机验收](APP_UPDATES.md)。
- 设置增加通知来源管理，工作台增加最近通知与收件箱。支持 CPE 飞书格式文本、可靠幂等、全文详情、分页筛选、离线已读和外部通知渠道。详见 [CPE 接入](CPE_INBOX.md)。

先升级兼容后端，再用既有正式签名覆盖安装。第一次获得更新功能仍需手动安装；以后版本通过应用内更新。云端 debug 包与现装签名不一定相同，不要卸载、清空数据或更换正式密钥来完成验收。

原签名构建、Firebase 真实配置、CPE 双发、系统安装器与锁屏通知均需本地真机接续。测试运行结果和交付限制见 [云端交付记录](CLOUD_FEATURE_DELIVERY.md)。
